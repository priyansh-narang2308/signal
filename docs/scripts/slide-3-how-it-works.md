# Slide 3: How it works

**Time:** about 55 seconds
**On screen:** the eight stages, the six gates, and the "Code decides / The LLM reads and writes" cards

---

This is the full run, from company name to discovery.

*[Move left to right across the top row.]*

SIGNAL **ingests** public filings: results, investor presentations, earnings call transcripts, RBI data and rating rationales. It **normalises** them into typed facts and checks them against accounting identities. It **builds the three expectations**, finds **breaches**, **triangulates** them across independent sources, **tries to falsify** them, **ranks** what's left, and writes up the **discovery.**

*[Point to the gates.]*

To be reported, a candidate has to pass **six gates.** The numbers must reconcile. At least two independent source families must back it. Peers must not explain it. It must survive the alternative explanations. It must predict something we didn't use to build it. And it must hold over time.

*[Point to the two cards at the bottom.]*

One design rule matters most here. **Code makes every decision and calculates every number.** The language model only reads text and writes prose. It never types a number, so it can't make one up.
