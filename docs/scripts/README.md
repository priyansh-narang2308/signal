## How to use these

- Read the lines in normal text. Lines in _italics inside brackets_ are stage directions. Don't read them out.
- **Bold** marks the words to stress.
- Speak slower than feels natural. About 140 words a minute is right for this script.
- Keep the prototype open in a second Chrome tab before you start screen-sharing, so the switch is one click.

## Before you go live

1. Open `submission/prototype/index.html` in Chrome. Press Cmd+Shift+R once to make sure the fonts and `script.js` load.
2. Set the browser zoom to 90% so each screen fits without scrolling too much.
3. Close every other tab and turn on Do Not Disturb.
4. Open the deck in PowerPoint in presenter view, so you can see these notes.
5. Do one full run-through against a timer.
